This iteration will build a simple RAG Model, which addresses one of the most important questions in human civilisation :
"Where is the greatest McDonalds in the world"

I have provided context to the model through a series of documents that are loaded. These are passed to the Model before it is spun up and iteracting with the user.

When the user asks such a pertinent question, it is given an unambiguous response.
